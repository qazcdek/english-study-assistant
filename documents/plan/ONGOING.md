# ONGOING

> **층** 진행 · **상태** 유효 · **강제** `backend/tests/test_doc_references.py`
> **읽어야 할 때** **진행 중인 일을 집거나 놓을 때.** 남이(또는 내일의 내가) 이어받을 때
> **위** [문서 지도](../00-index.md) · **함께** [ROADMAP](ROADMAP.md) · [ISSUES](ISSUES.md) · [DONE](DONE.md)

**지금 열려 있는 일의 세부.** `[~]` 인 태그만 여기 있고, 끝나면 [DONE](DONE.md) 으로
옮기고 이 문서에서 **지운다.**

```
ROADMAP · ISSUES   [ ]  한 줄.  무엇을 할지만
      ↓ 시작하면서  [~]
ONGOING            진행하면서 적는다.  계속 고친다
      ↓ 끝나면     [x]
DONE               무엇을 / 왜 / 어떻게.  **다시 고치지 않는다**
설계 문서           판단이 반영된다.  계속 유효하다
```

## 왜 이 문서가 필요한가

전에는 세부를 둘 자리가 **DONE 뿐**이었다. 그런데 DONE 은 **끝난 뒤에** 쓰는 문서다.
그래서 아직 안 한 일의 세부는 **어디에도 없었고**, 한 줄 요약이 그 역할을 떠맡았다.

한 줄은 길이가 모자란 게 아니라 **틀려도 맞아 보인다.** 실제로
`M2-T1 작문 연습 결과를 저장 — 지금은 채점하고 버린다` 가 그랬다. 저장은 **이미 되고
있었는데**, 그 한 줄이 그럴듯해서 아무도 의심하지 않았다. 코드를 읽고서야 알았다.

그래서 이 문서의 첫 칸이 **전제**다. "지금 어떻게 돼 있나" 와 **어디서 확인했나**를
함께 적는다. 확인 출처가 없는 전제는 짐작이고, 짐작은 조용히 낡는다.

## 형식

```
### <태그> · <한 줄 요약>
시작 <날짜> · 갱신 <날짜>

- **전제** 지금 어떻게 돼 있나. **어디서 확인했나**를 함께 적는다
- **결정** 무엇을 하기로 했나, 왜. 버린 안도 적는다
- **막힌 것** 못 가는 이유 — 물어야 할 것, 재야 할 것
- **다음 걸음** 바로 다음에 할 하나
```

네 칸을 다 채울 필요는 없다. 다만 **전제와 다음 걸음**은 비워 두지 않는다 —
그 둘이 없으면 내일 이어받을 수 없다.

### M13-T1 · 글감 출처를 쳐 보고 고정한다
시작 2026-10-23 · 갱신 2026-10-23

- **전제** 아래는 **전부 2026-10-23 에 직접 호출해 확인한 것**이다. 서드파티 글이
  아니라 응답을 보고 적었다. 출처를 다시 고르기 전에 이 표를 읽는다.

  | 후보 | 쟀을 때 | 결과 |
  |---|---|---|
  | **가디언** Content API | `api-key=test` → `401 Unauthorized` | **무료 키를 받아야 잴 수 있다.** 본문·조회수 둘 다 **미확인** |
  | **VOA** 영어 (USA·Immigration) | RSS 최신 `2025-03-15` | **멈췄다.** 2025 USAGM 삭감 시점 |
  | **VOA** Learning English (전 피드) | RSS 최신 `2025-04-29` | **멈췄다** |
  | **VOA** Dari·Korean·Mandarin·Kurdish | RSS 최신 `2026-10-21` | 살아 있다 — **영어가 아니라 못 쓴다** |
  | **NPR** Story API | 문서 | `2025-07` 폐지 → CDS(회원사 전용). 약관도 개인·비영리 한정 |
  | **Wikinews** | 문서 | `2026-05-04` 부터 **읽기 전용**. CC BY 2.5 라 번역 호환도 걸린다 |
  | **The Conversation** | 재게시 가이드 | CC BY-**ND**. *"translations … require author approval"* |
  | **ProPublica** | 재게시 약관 | CC BY-NC-ND + *"can't republish wholesale, or automatically"* |
  | **NYT** Most Popular | 문서 | **조회수를 주는 유일한 곳**이지만 본문을 안 준다 |

  `open-platform.theguardian.com` 은 이 개발 환경에서 **차단돼 있어** 공식 문서와
  약관을 열지 못했다. 가디언 쪽 서술은 전부 서드파티 글이므로 **근거로 쓰지 않는다.**

- **결정**
  1. **출처를 갈아 끼울 수 있는 자리로 만든다.** 재 보니 "무료 · 살아 있음 ·
     본문 전체 · 번역 허용" 을 다 만족하는 곳이 **미국 쪽에 없다.** 영·미 한 곳씩의
     균형은 목표로 남기고, 구조를 먼저 그렇게 만들어 둔다.
  2. **분량을 설정값으로 둔다.** 기사 전문을 올리는 것과 몇 문단만 발췌하는 것은
     저작권에서 전혀 다른 일인데(전문 복제 ↔ 인용), 가디언 약관을 읽어야 갈린다.
     코드가 어느 쪽이든 되게 만들어 두면 **정한 뒤에 다시 안 짓는다.**
  3. **번역이 라이선스 선택을 지배한다.** 이 앱의 출력에 한국어 번역이 들어가고,
     번역은 거의 모든 재게시 라이선스에서 **명시적으로 2차적 저작물**이다. ND 가
     붙은 출처는 그래서 전부 탈락했다. 퍼블릭 도메인이거나 명시 허가가 필요하다.
  4. **조회수는 근사치로 간다.** "어제 기사 중 조회수 최고" 를 그대로 주는 API 가
     없다. 아침마다 인기 목록을 읽어 **어제 발행된 것만 걸러 1위**를 잡는다.
     동률이면 최신. 의도에는 맞고, 날짜별 순위를 주는 곳이 없다는 사실에도 맞는다.

- **막힌 것**
  - **가디언 무료 키** — 받아야 본문(`show-fields=body`)과 조회수(`showMostViewed`)가
    실제로 오는지 잴 수 있다. 가디언 자체 Scala 클라이언트에 `showMostViewed()` 가
    있다는 단서까지만 있고 **확인은 안 됐다.** 키는 사용자가 등록한다.
  - **가디언 약관** — 무료 개발자 키가 비영리 한정인지, 번역·전문 게시를 허용하는지.
    도메인이 차단돼 제가 못 읽는다. **운영자가 읽고 판단할 영역**이다.
  - **미국 자리** — 위 표에서 살아남은 곳이 없다. 선택지는 셋이다:
    (a) 가디언 하나로 먼저 돌린다 (b) 발췌를 인용 범위로 좁히면 RSS 가 있는
    어느 매체든 쓸 수 있다 (c) VOA **2025년 이전 영어 기사**를 보관용 글감으로 쓴다
    — 퍼블릭 도메인이라 법적으로 가장 깨끗하지만 "어제의 뉴스" 가 아니다.

- **다음 걸음** 가디언 무료 키를 받아 `show-fields=body` 와 `showMostViewed` 를
  실제로 호출해 **무엇이 오는지 적는다.** 그걸 재기 전에는 `M13-T2` 이후를 짓지 않는다
  — 스키마가 응답 모양에 달려 있다.
