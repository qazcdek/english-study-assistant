# 01. 제품 기획서 — English Study Assistant

## 1. 한 줄 요약

영어 문장/문단을 입력하면 로컬 LLM이 **번역 · 표현 풀이 · 문장 구조 · 총평** 네 가지로 정리해 주는 1인용 영어 학습 웹 앱.

## 2. 문제 정의

기존 사전/번역기는 단어 단위 의미는 주지만, 실제 원문 독해에서 필요한
"이 표현이 얼마나 흔한가, 격식체인가, 어떤 분야 글에서 쓰이나"를 알려주지 않는다.
LLM 채팅으로 매번 같은 프롬프트를 붙여넣는 것은 번거롭고 출력 형식이 매번 흔들린다.

**→ 형식을 고정하고, 붙여넣기 한 번으로 끝나게 만든다.**

## 3. 대상 사용자

- 원문(뉴스, 칼럼, 기술 문서, 소설)을 읽다가 막히는 중상급 학습자
- 로컬에서 llama.cpp 서버를 돌릴 수 있는 개발자 본인

## 4. 핵심 사용자 흐름

```
[영어 문장 붙여넣기] → [분석 버튼] → [카드가 하나씩 채워짐] → [필요하면 복사 / 저장]
```

1. 사용자가 텍스트 영역에 영어 문장 또는 문단을 붙여넣는다.
2. "분석" 버튼을 누른다 (Cmd/Ctrl + Enter 도 동작).
3. 네 개 섹션 카드가 즉시 자리를 잡고, **완성된 파트부터 차례로 채워진다.**
   진행 중인 카드는 스켈레톤과 "분석 중" 표시를 보여 준다.
4. 한 파트가 실패해도 나머지는 정상적으로 채워진다.
5. 표현 풀이 표에서 예문은 기본적으로 가려져 있다. **[✏ 직접 써보기]** 를 누르면
   한국어 뜻만 보고 영작하고, LLM이 채점해 준다 (06-practice.md).
6. 전부 끝나면 결과 전체를 마크다운으로 복사할 수 있다.

로컬 모델에서 번역은 **3~8초**, 전체는 **40~50초** 정도 걸린다.
한 번에 받으면 32초지만 첫 글자까지 32초를 기다려야 하므로, 체감을 우선해 분할을 택했다
(05-benchmark.md).

## 5. 출력 섹션 정의 (MVP 범위)

| # | 섹션 | 내용 | 형태 |
|---|---|---|---|
| 1 | 자연스러운 번역 | 직역이 아닌, 한국어로 읽히는 번역 | 문단 |
| 2 | 표현 풀이 | 고급 어휘 / 관용구 / Phrasal Verb / 문법 포인트 | 표 (표현, 유형, 의미 및 설명, 예문) + 행별 작문 연습 |
| 3 | 문장 구조 | 핵심 구문 조각별 문법 해설 | 불릿 목록 |
| 4 | 총평 | 분야, 톤, 격식 수준, 문체, 꼭 챙길 표현 | 요약 블록 |

### 5.1 총평 항목

총평은 **"이 글이 어떤 분야에서 어떤 톤으로 쓰였고, 무엇을 챙겨 가야 하는가"** 를 답한다.
표현이 얼마나 흔한지 같은 빈도 판단은 하지 않는다 — 모델이 일관되게 답하지 못했고
(같은 문단에 `자주`와 `매우 드묾`이 갈렸다), 판단 대상이 문단인지 개별 표현인지도 모호했다.

- **분야**: 어떤 분야의 글인지 (예: 경제·금융 시사 논평, 친구 간 일상 대화)
- **톤**: 글쓴이의 태도·어조 (예: 유머와 비유를 섞은 분석적 어조)
- **격식**: 매우 격식 / 격식 / 중립 / 비격식 / 속어에 가까움
- **문체**: 문어체 / 구어체 / 혼합
- **꼭 챙길 표현**: 표현 풀이 표에서 특히 중요한 1~3개. 표의 해당 행에 ★ 로 표시된다
- **코멘트**: 그 표현들이 왜 중요하고 어디에 써먹을 수 있는지 두세 문장

### 5.2 작문 연습

표현 풀이의 예문을 가리고 한국어 뜻만 보고 영작한 뒤 채점받는다.
읽고 이해하는 데서 멈추지 않고 직접 써 보게 하는 것이 목적이다.
판정은 `정확함 / 통함 / 다시` 세 단계이며, 목표 표현을 실제로 썼는지는 따로 표시한다.
근거와 설계는 [06-practice.md](06-practice.md) 참고.

## 6. 범위 밖 (Non-goals, MVP 기준)

- 회원가입 / 로그인 / 멀티 유저
- 서버 측 영구 저장 (DB) — 히스토리는 브라우저 localStorage 로만
- 음성 (TTS/STT)
- 외부 상용 LLM API 연동 (llama-server 만)
- 모바일 전용 앱

## 7. 향후 확장 후보

- 작문 연습 결과 저장 — 틀린 표현만 모아 다시 풀기
- 분석 히스토리 검색 및 즐겨찾기
- 표현 풀이 표에서 선택한 항목만 모아 단어장 / Anki 내보내기
- 스트리밍 응답으로 체감 대기 시간 단축
- 난이도(CEFR) 추정 및 유사 예문 생성

## 8. 성공 기준

- 문단 하나(약 3~5문장) 분석이 로컬 LLM에서 **30초 이내** 완료
- 출력 JSON 스키마 검증 실패율 **5% 미만** (재시도 1회 포함)
- 붙여넣기부터 결과 확인까지 클릭 2회 이내
